# Pi agent configuration

This directory is the Pi configuration root.

Committed source-of-truth files live here:

- `settings.json` — Pi settings and package declarations.
- `models.json` — optional custom model/provider definitions.
- `extensions/`, `skills/`, `prompts/`, `themes/` — local Pi resources.

Do not commit generated package installs or sessions:

- `npm/` and `git/` are generated by `pi install` / startup package restore.

Provider auth is `auth.json`. The Kagi search extension token is
`kagi-search.json`.

Keep plaintext secrets out of normal git; commit encrypted copies (for example
`auth.json.sops` and `kagi-search.json.sops`) or use git-crypt and adjust
`.gitignore` accordingly.
